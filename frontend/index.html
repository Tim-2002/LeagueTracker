🔄 Riot Games API Sync & Datenbank

1. Spiele eines beliebigen Spielers über die Riot API laden

Mit deinem eigenen Riot API-Key kannst du jeden beliebigen Spieler (dich selbst, Freunde oder Pro-Player) über seine Riot-ID (Name#Tag) abrufen. Alle Spieler werden sauber getrennt nach ihrer PUUID lokal in data/leaguetracker.db gespeichert. Deinen kostenlosen Development API-Key (24h gültig) erhältst du direkt auf developer.riotgames.com.

🔑 Neuen API-Key holen (developer.riotgames.com) ↗

2. Demo-Modus (Zum Testen ohne API-Key)

Erzeugt 80 realistische Matches über 60 Tage (Ahri, Orianna, Jinx, Viego) inkl. Laning-Timeline-Daten, damit du die Gruppierungen (1, 5, 10, 20 Spiele) sofort ausprobieren kannst.
